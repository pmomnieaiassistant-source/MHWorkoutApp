MH LIFT SESSION FORMAT
Instructions for an AI assistant (ChatGPT, Claude, etc.)

You will be given a workout in any form (notes, a photo transcript, a program from a book or website). Rewrite it in the format below so it can be pasted into the MH Lift app. Reply with ONLY the formatted text in a single code block, no explanations. If something does not fit the format, put it on a "> " note line rather than leaving it out.

------------------------------------------------------------
STRUCTURE
------------------------------------------------------------
# Session name             Starts a session. Several sessions in one reply are fine, one "#" each
                           (e.g. a 4-week program = "# Week 1 Day 1", "# Week 1 Day 2", ...).
tags: strength, barbell    Optional, right under the session name.
notes: anything            Optional session note.
## Phase name              Starts a phase: Warm-up, Strength, Conditioning, Cool-down, etc.
Card line                  A line that does NOT start with "-" is a card (one exercise or one block).
- detail line              Lines starting with "- " belong to the card above.
  - nested line            Indented "- " lines belong to the item above (parts of a complex, alternatives).
> note                     Shown to the athlete during the workout.
// comment                 Ignored.

------------------------------------------------------------
ONE EXERCISE WITH SETS
------------------------------------------------------------
Back Squat 5x5 @ 225 lb rest 3:00
Incline DB Press 4x8-10 @ 70 lb RIR 2 rest 2:00 tempo 3-1-1-0
Press 3x5+ @ 115 lb             "+" = last set as many reps as possible
Pull-up 3x8                     no load = body weight
Plank 3x30s
Pistol Squat 3x5/side

When sets differ, write the name alone, then one "- " line per set:
Deadlift
- warmup 5 @ 135 lb
- warmup 3 @ 225 lb
- 5 @ 75% TM
- 3 @ 85% TM
- 1+ @ 95% TM
rest: 3:00

Set line kinds: warmup, backoff, top, drop, mini, amrap (default is a working set).
- backoff 3x5 @ -10%                    (percent of the set before)
- drop 10 @ 50 lb > 8 @ 40 lb > max @ 30 lb
- mini 5 x 5 rest 5s                    (myo-rep mini sets)
Trap Bar Jump 3 x 6/2 @ 95 lb           (cluster: 3 sets of 6 done in clusters of 2)
intra-rest: 20s
