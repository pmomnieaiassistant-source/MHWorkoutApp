# MH Lift

Personal workout app for iPhone: build sessions (any format, from straight sets to EMOMs and run intervals), plan them into weeks with reusable blocks, run them step by step with timers, and see it all next to your Whoop data.

- Open on the phone, then Share → Add to Home Screen.
- Back end setup (Google Sheet + Apps Script + Whoop): [backend/SETUP.md](backend/SETUP.md)
- Session format: [docs/session-format.md](docs/session-format.md) · guide for LLMs: [syntax.txt](syntax.txt)
- Parser tests: `node tests/parser.test.js`
